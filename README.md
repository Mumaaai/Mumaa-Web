# MUMAA - Calm AI Parenting Companion (Frontend)

MUMAA is a modern, AI-powered web application designed to support mothers on their parenting journey. It provides a serene, non-judgmental space for tracking baby growth, logging daily activities, and getting gentle guidance from a calm AI companion.

## 🚀 Features
- **AI Cry Translator**: Softly translate baby cries to understand their needs.
- **Smart Activity Logs**: Easily log feeding, diaper changes, and sleep patterns.
- **Growth Tracker**: Monitor your baby's weight and height milestones.
- **Memory Journal**: Save precious moments with photos and notes.
- **Lullaby & Play**: Curated AI-driven play suggestions and soothing lullabies.

## 🛠 Tech Stack
- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS 4 & Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router (HashRouter for GitHub Pages compatibility)
- **Authentication**: Google OAuth 2.0

## 📦 Deployment
This frontend is optimized for **GitHub Pages**.
- The build output is configured for the `/docs` folder.
- Assets use relative paths for sub-folder compatibility.

### Local Development
```bash
npm install
npm run dev
```

### Build for Production
```bash
npm run build
```
